## 💡 The five-to-the-n Pythagorean Rational System

In conventional illustration software (Illustrator, Figma), Bézier handles drift on arbitrary floating-point coordinates (`x: 341.8723...`), introducing irrational roots ($\sqrt{2}, \sqrt{3}$) and rounding errors that cause micro-distortion, non-closing spline contours, and trigonometric drift across glyph sets.

Raystar replaces floating-point drift with the **five to the n Pythagorean Rational System**:
- **Modular Lattice**: All knots and handles snap to exact rational moduli powers of 5 ($5, 25, 125, 625$).
- **Exact Rational Slopes**: Handle tangents snap to primitive Pythagorean triples generated by powers of 5:
  - $5^1 = 5$: The $(3, 4, 5)$ triple yields exact rational sines and cosines ($\sin = 0.6, \cos = 0.8$) and slopes $\pm 3/4, \pm 4/3$.
  - $5^2 = 25$: The $(7, 24, 25)$ triple yields exact rational sines and cosines ($\sin = 0.28, \cos = 0.96$) and slopes $\pm 7/24, \pm 24/7$.
  - $5^3 = 125$ and $5^4 = 625$: High-order harmonic rational triples $(44, 117, 125)$ and $(336, 527, 625)$.
- **Zero Trigonometric Drift**: Inner dot products, vector lengths, and rotations evaluate in exact rational arithmetic $\mathbb{Q}$ without square roots or transcendental functions.

## 🖥️ The Dual-Window Experience

The application operates as a **dual-window browser-native vector workstation**:
1. **Window 1: Flight Corridor Cockpit** ([http://localhost:8000/flyover.html](http://localhost:8000/flyover.html)): Fly down a 2,400-tile architectural corridor inscribed with the opening of the *Declaration of Independence* — its first 2,400 characters, from "When in the Course of human events" to "free and independent States" (40 ranks by 60 columns). Click any character tile in mid-flight to highlight it and open Raystar Studio.
2. **Window 2: Raystar VectorEngine Studio** ([http://localhost:8000/raystar.html](http://localhost:8000/raystar.html)): Sculpt Bézier splines constrained to 5-adic rational moduli over a Tan underlay (`#d2b48c`), generate procedural Gothic architectural flourishes with the Overarch engine, navigate with MacBook Pro two-finger pan and pinch-zoom, and transmit updated SVGs back to flight in real time with zero page reloads.

## 🕹️ Interactive Controls Reference

### Flight Corridor Controls (`flyover.html`)
- **`W` / `S`** (or `↑` / `↓`): Traverses ranks 1 to 40 down the text corridor.
- **`A` / `D`** (or `←` / `→`): Slides laterally across the 60 columns.
- **`Space` / `Shift`** (or Altitude Slider): Adjusts camera altitude from 100m down to 1m deck skim.
- **`[` / `]`**: Discrete rank stepping forward or backward by one tile rank.
- **Mouse Click on Tile**: Highlights letter tile and displays cockpit preview.
- **`[ 🚀 RAYSTAR ]`**: Opens `raystar.html?char=<CHAR>` for rational spline editing.
- **`[ 📷 CAPTURE SCREENSHOT ]`**: Captures viewport screenshot.

### Raystar Studio Controls (`raystar.html`)
- **Two-Finger Drag (Touchpad) / Space + Left Drag**: Fluid pan across canvas.
- **Pinch-to-Zoom (Touchpad) / Mouse Wheel**: Smooth zoom centered at cursor.
- **`F` / Double-Click / Double-Tap**: Auto-fits entire design into view with 25% margin.
- **`[ ⚙️ Preferences ▾ ]`**: Configure MacBook trackpad vs mouse wheel mode, natural pan, and sensitivity.
- **Arrow Keys** (`↑` `↓` `←` `→`): Steps picked knot or handle by active five to the n modulus ($5, 25, 125, 625$).
- **`Shift + Arrow Keys`**: Translates all 4 control points of the active curve simultaneously.
- **`[` / `]`** or **`Tab`**: Cycles active selection ($P_0 \leftrightarrow C_1 \leftrightarrow C_2 \leftrightarrow P_3$).
- **`J` / `K`**: Steps to next or previous curve in the design.
- **`Cmd + Z` / `Cmd + Shift + Z`**: 40-step history manager covering drags, snaps, renames, and deletions.
- **`[ More ]` Button**: Prompts Overarch procedural engine for fresh Gothic architectural ornaments.
- **`[ ✦ Adopt into Design ]`**: Promotes pastel suggestion into active working curves.
- **`[ 💾 Return SVG to Flight ]`**: Compiles rational SVG, broadcasts across `alphagamma_glyph_bridge`, and refocuses cockpit.

## ⚡ Performance: Node.js Toolchain vs Python Baseline

- **Letter Library Build (156 glyph keys, 155 SVG files)**:
  - Python: `python3 build_letter_library.py` (0.704s)
  - Node.js: `node scripts/build-letter-library.js` (0.179s)
  - Result: **3.9x Faster**, 0 external npm dependencies
- **Design Library Build (123 items — 51 designs, 72 ornaments)**:
  - Python: `python3 build_design_library.py` (0.714s)
  - Node.js: `node scripts/build-design-library.js` (0.291s)
  - Result: **2.5x Faster**, 0 external npm dependencies
- **Dev Server I/O**:
  - Python: `python3 serve.py 8000` (blocking I/O)
  - Node.js: `node scripts/serve.js 8000` (non-blocking V8 event loop)
  - Result: Lower unified RAM pressure on 8GB Apple Silicon
- **Edge Production Build**:
  - Astro static compilation in `site/dist/`
  - A GitHub Pages workflow is written but not dispatched; Pages is not enabled, so nothing is deployed yet

## 🔔 Standing Rules & Assistant Guidelines

All automated agents operate under the standing protocols defined in [docs/AGENTS.md](file:///Users/thomaskelly/developer/grid-8/docs/AGENTS.md):
1. **Pre-Notification Log Inspection**: Inspect server logs (`scripts/serve.js` / background task logs) and run unit tests before sounding chime.
2. **Audible Notification**: Trigger CoreAudio chime (`node scripts/notify.js -m "..."` or `python3 notify.py -m "..."`) upon turn completion.
3. **Anti-Loop Circuit Breaker**: Halt after two consecutive tool failures of the same category.
4. **Immediate Sandbox Escalation**: Request `BypassSandbox: true` immediately on permission denial.
5. **Zero Active Polling**: Never run polling loops; rely on reactive runtime wakeups.
6. **Continuous Atomic Commits**: Commit clean working trees after every completed milestone.
