# Code of conduct

This project follows the Contributor Covenant, version 2.1.

Be respectful; assume good faith; critique the work, not the person. Harassment
and discriminatory language are not welcome. Maintainers may remove comments,
commits or contributions that break this, and will say why.

Report concerns to the repository owner privately. Reports are handled
confidentially. Enforcement follows the Contributor Covenant's ladder:
correction, warning, temporary ban, permanent ban.

Full text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
